## 背景・課題

バックオフィス業務の代行サービスを運営するにあたり、顧客情報・案件・日々のタスクが分散して管理されていました。担当者ごとに進め方が異なり、対応状況の可視化と品質の標準化が課題でした。

## 取り組み

- React Router v7（フレームワークモード）+ Prisma + PostgreSQL でサービスの基幹システムを構築
- 顧客・案件・タスクを一元管理し、対応状況をチームで共有できる設計に
- リッチテキストエディタによるドキュメント作成や、AWS SES を用いたメール通知を実装
- Docker / Kamal によるコンテナ運用で、継続的なリリースを実現

## 成果

- 代行業務のオペレーションをひとつのシステムに集約
- 属人化していた進め方を標準化し、対応状況を可視化
