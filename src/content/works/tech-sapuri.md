## 背景・課題

プログラミング学習では、環境構築でつまずくことが少なくありません。ブラウザだけで、すぐにコードを書いて学べる環境が求められていました。

## 取り組み

- Ruby on Rails + React で学習プラットフォームを構築
- Monaco / Ace エディタをブラウザに組み込み、その場でコードを書ける学習UIを実装
- 教材コンテンツやユーザー認証（Devise）を整備
- Docker で開発・運用環境を統一

## 成果

- 環境構築なしで、ブラウザだけでコーディング学習ができる環境を提供
- 手を動かしながら学べる学習体験を実現
