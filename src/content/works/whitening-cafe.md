## 背景・課題

店舗での予約受付を、Web上で完結できるようにしたいというニーズがありました。メニューや予約枠の管理と、お客様が迷わず予約できる導線の両立が求められました。

## 取り組み

- Ruby on Rails + React で店舗予約システムを構築
- メニュー・予約枠・顧客情報の管理機能を実装
- Tailwind CSS でスマートフォンでも使いやすいUIを設計
- Docker で開発・運用環境を整備

## 成果

- お客様がWebから24時間予約できる仕組みを実現
- 店舗側の予約管理をシステム上で一元化
