## 背景・課題

フロントエンド開発やAPI連携の学習では、気軽に叩ける題材となるデータソースがあると便利です。そこで、人気作品のキャラクター情報を題材に、誰でも無料で使える公開APIを作成しました。

## 取り組み

- キャラクターや「柱」などの情報を JSON データとして整備
- GitHub Pages 上でホスティングし、無料で使える静的APIとして公開
- Docker でデータ生成・確認の環境を構築

## 成果

- 誰でも無料で利用できる公開APIとして提供
- 学習・プロトタイピング向けのデータソースとして活用できる形に
