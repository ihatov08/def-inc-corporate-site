取引先ロゴの置き場です。

- SVG を推奨（拡大しても崩れず、ファイルサイズも小さいため）。SVG がなければ背景透過の PNG / WebP。
- 縦横比はまちまちで構いません。表示側で高さ 28px 前後に揃え、はみ出さないよう調整しています。
- ファイル名は src/data/clients.ts の logo に書いたパスと一致させてください（例: personol-career.svg）。
- 他社ロゴは先方の許諾とロゴ利用ガイドラインに従って使用してください。改変・色変更が禁止されている場合があります。
- ダークテーマでも読めるかを確認してください。濃い色のロゴは暗い背景に沈みます。
  沈む場合は src/components/ClientLogos.astro の .client-plate に白背景を当てるか、
  白抜きロゴを別途用意して `@media (prefers-color-scheme: dark)` で差し替えてください。
